Higgsfield [tiene en marcha una promoción de cashback sobre el gasto en API](https://higgsfield.ai). No vamos a intentar disuadirte.

Trae tu propia clave de Higgsfield a Comfy Router y tus generaciones se ejecutan en **tu** cuenta de Higgsfield, así que cuentan como tu gasto en Higgsfield y lo que esa promoción valga para ti es tuyo. Sigues obteniendo un endpoint, un cliente y la misma forma de solicitud que cualquier otro modelo en Router.

<Note>
  Higgsfield es el propietario de la promoción y de sus términos. Consulta la oferta vigente en su sitio antes de basar tus planes en ella.
</Note>

## Qué cambia cuando usas tu propia clave

| | Tu clave de Comfy | Tu clave de Higgsfield |
| --- | --- | --- |
| Facturado a | Tus créditos de Comfy | Tu cuenta de Higgsfield |
| Créditos de Comfy cobrados | Sí | **Ninguno** |
| Endpoint, cuerpo de la solicitud, respuesta | Igual | Igual |

Todo lo demás de la llamada es idéntico. No cambias tu código para cambiar de clave: guardas una clave y Router la usa.

<Steps>
  <Step title="Obtener una clave API de Higgsfield">
    Crea una clave en tu [cuenta de Higgsfield](https://higgsfield.ai). Higgsfield la emite como un **par de id y secreto**, y Comfy la guarda como la cadena única `id:secret`. Conserva los dos puntos y no la separes en dos campos.
  </Step>

  <Step title="Guardarla en Comfy">
    Abre [**Claves de proveedor**](https://platform.comfy.org/profile/provider-keys) en tu perfil de Comfy, elige **Higgsfield** y pega el valor `id:secret`.

    Tu clave se cifra en reposo y la API nunca la devuelve una vez guardada. Router la lee solo para firmar tus propias llamadas.
  </Step>

  <Step title="Crear una clave API de Comfy">
    Esta es la clave que te autentica ante Comfy, aparte de la de Higgsfield. Créala en [tu espacio de trabajo de Comfy](https://platform.comfy.org/profile/api-keys) y luego define:

    ```bash
    export COMFY_API_KEY="comfyui-..."
    ```

    Mantén las claves API en tu servidor o en tu entorno local. Estos ejemplos son para una terminal o un servidor, no para JavaScript en el navegador.
  </Step>

  <Step title="Ejecutar un modelo">
    Copia y pega un fragmento de código de los que aparecen abajo para el modelo que seleccionaste.
  </Step>
</Steps>

## Modelos

<Tabs><Tab title="Kling 3.0 std">
    Equilibrio entre calidad y velocidad. `duration` acepta de 3 a 15 segundos.

    <CodeGroup>

    ```bash cURL
    curl --max-time 660 \
      https://api.comfy.org/v2/models/higgsfield/higgsfield-kling-3-std \
      -H "X-API-Key: $COMFY_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{
        "prompt": "A cinematic glass pavilion in a misty pine forest at sunrise",
        "duration": 5,
        "aspect_ratio": "16:9",
        "cfg_scale": 0.5,
        "sound": "on"
      }'
    ```

    ```python Python
    # Python 3.10+
    # Instalar: python -m pip install "comfy-sdk>=0.3.0"

    from comfy_sdk import Comfy

    # Comfy lee COMFY_API_KEY del entorno.
    with Comfy() as client:
        result = client.models.run(
            "higgsfield/higgsfield-kling-3-std",
            {
                "prompt": "A cinematic glass pavilion in a misty pine forest at sunrise",
                "duration": 5,
                "aspect_ratio": "16:9",
                "cfg_scale": 0.5,
                "sound": "on",
            },
            timeout=660.0,
        )

    print("video:", result["video"]["url"])
    ```

    ```typescript TypeScript
    // Node.js 22+
    // Instalar: npm install "@comfyorg/sdk@>=0.4.0" --save-dev tsx

    import { comfy } from "@comfyorg/sdk";

    type HiggsfieldResult = { video: { url: string } };

    const { data } = await comfy.models.run<HiggsfieldResult>(
      "higgsfield/higgsfield-kling-3-std",
      {
        prompt: "A cinematic glass pavilion in a misty pine forest at sunrise",
        duration: 5,
        aspect_ratio: "16:9",
        cfg_scale: 0.5,
        sound: "on",
      },
      { timeoutMs: 660_000 },
    );

    console.log("video:", data.video.url);
    ```

## Leer el resultado

`run` devuelve el documento terminal propio de Higgsfield. La URL de descarga está en `video.url`:

```json
{
  "status": "completed",
  "request_id": "0c4a9e17-5b82-4d66-9a3f-7c1e08b45d29",
  "video": { "url": "https://example.com/generated.mp4" }
}
```

Guárdalo de inmediato:

```bash
curl --fail --location "PASTE_VIDEO_URL_HERE" --output out.mp4
```

El router consulta a Higgsfield por ti, así que `queued` e `in_progress` nunca te llegan: recibes el documento finalizado o un error. `nsfw`, `failed` y `canceled` son los fallos terminales; `failed` incluye el detalle en `error`.

## Notas

- **La validación ocurre antes de que se llame a Higgsfield.** Un cuerpo fuera de los límites publicados devuelve `422` con el nombre del campo que falla, y no se envía nada al servicio upstream, así que una solicitud incorrecta no te cuesta nada.
- **Tu clave solo se usa para los modelos para los que tienes una clave.** Guardar una clave de Higgsfield no cambia en nada cómo se factura cualquier otro proveedor en Router.
- Los esquemas completos de solicitud y respuesta de cada modelo están en la [Referencia de Comfy Router](/es/development/comfy-router/reference).
